# Numerical Methods

This repository is a notebook-based laboratory course for numerical methods. Every lab is stored as a numbered `.ipynb` file with explanation, runnable code, sample output, and a practice prompt.

## Course roadmap

| Folder | Topics |
|---|---|
| `root_finding/` | Bisection, Newton-Raphson, and secant methods |
| `linear_systems/` | Gaussian elimination, Jacobi, Gauss-Seidel, and LU factorization |
| `interpolation/` | Lagrange and Newton forward interpolation |
| `numerical_integration/` | Trapezoidal, Simpson, and Gaussian quadrature |
| `numerical_differentiation/` | Finite differences and Richardson extrapolation |
| `differential_equations/` | Euler and fourth-order Runge-Kutta methods |
| `optimization/` | Gradient descent and least-squares estimation |
